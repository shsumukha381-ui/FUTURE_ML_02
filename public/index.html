NLP Pipeline
  • Noise Removal & URL Stripping — Removes URLs, email addresses, and HTML tags from ticket text.
  • Emoji & Special Character Handling — Strips punctuation and special characters, keeping only alphanumeric text.
  • Normalization — Lowercases text, collapses whitespace, and filters short tokens (< 2 chars).
  • Stopword Removal — Removes English stopwords using NLTK corpus.
  • Lemmatization — Reduces words to base form using WordNet lemmatizer.
  • TF-IDF Vectorization — Extracts up to 10,000 features with unigrams + bigrams, sublinear TF scaling.
  • Dual Model Inference — Predicts Category (LinearSVC + Platt calibration) and Priority (LogisticRegression).

Endpoints

Quick Start
JavaScript (fetch) 
const response = await fetch('http://localhost:8000/predict', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: 'My laptop screen is broken and I need a replacement'
  })
});

const result = await response.json();
console.log(result.category);    // e.g. "Hardware"
console.log(result.priority);    // e.g. "Medium"
console.log(result.category_confidence);  // e.g. 0.8723
Python (requests) 
import requests

response = requests.post(
    'http://localhost:8000/predict',
    json={'text': 'My laptop screen is broken and I need a replacement'}
)

result = response.json()
print(f"Category: {result['category']}")       # e.g. "Hardware"
print(f"Priority: {result['priority']}")       # e.g. "Medium"
print(f"Confidence: {result['category_confidence']}")  # e.g. 0.8723
